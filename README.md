# Moamen Essam portfolio

Plain HTML, CSS and JavaScript. No build step, no dependencies.

- `index.html` content
- `style.css` styling
- `script.js` project filter and number animations
- `assets/Moamen_Essam_Data_Analyst_CV.pdf` the CV behind the Download CV button

## Run
Open `index.html` in a browser.

## Publish free on GitHub Pages
1. Create a repo named `moamenesam.github.io` (or any name).
2. Upload these files to the root.
3. Settings > Pages > Deploy from branch `main`, folder `/ (root)`.
Netlify Drop (app.netlify.com/drop) also works: drag the folder in.
